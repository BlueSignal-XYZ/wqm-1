Why this matters

The network is how this unit uploads readings and receives updates. {% if lora_enabled %}LoRa runs alongside it as a long-range backup, but it is far slower and carries less — the network is the path you want working.{% endif %} Either way, control decisions are made on this unit, so a dropped network never stops monitoring, logging, or fail-safe behaviour.
