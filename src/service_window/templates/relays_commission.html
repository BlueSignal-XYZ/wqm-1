Commission relay CH{{ channel }}

Before you start

A dead Pi cannot energise a coil. The only state a crashed or unpowered device can hold is de-energised, so that is what “fail-safe” always means here. What it does physically depends on how this channel is wired:

  • NC — de-energised leaves the load RUNNING
  • NO — de-energised leaves the load STOPPED

Anything that must survive a power cut — aeration, circulation — has to be wired NC. The firmware refuses a fail-safe = run channel on an NO contact, because that fail-safe cannot happen.

These outputs are pilot duty: a contactor coil, a 24 V solenoid, or a VFD enable input. Never a motor or a line-voltage load directly. Limits are {{ '%.0f'|format(max_a_no) }} A on NO and {{ '%.0f'|format(max_a_nc) }} A on NC.
