ORP Offset Calibration

Analog ORP is non-functional on PCBA Fin_3 — AIN3 is a spare pin with no ORP circuit behind it, so this page cannot calibrate a base-unit channel. ORP ships as an optional RS485 probe; calibrate that under RS485 Sensors, where the probe holds its own calibration state.

1. Place the probe in a known ORP solution (e.g. 225 mV).

2. Read the measured mV the sensor reports on the Sensors page — this is a converted value, not a raw voltage, so there is no live-voltage fill here.
